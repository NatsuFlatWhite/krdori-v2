# krdori-v2

**krdori-v2**는 뱅드림! 걸즈 밴드 파티! 한국 서비스 버전, 통칭 **한도리**를 위한 비공식 로컬 서버 구현체입니다.

[RainbowUnicorn7297/krdori-local](https://github.com/RainbowUnicorn7297/krdori-local)을 기반으로 미구현 API와 로컬 상태 저장 기능을 추가하였으며, 기존에 정상적으로 동작하지 않던 일부 시스템을 복구하고 확장하였습니다.

> 본 프로젝트는 게임 서버 프로토콜 분석, 인게임 패킷 처리 구조 연구 및 로컬 환경 테스트를 목적으로 제작된 비상업 프로젝트입니다.  
> Bushiroad, BanG Dream! 및 관련 권리자와 아무런 관련이 없는 비공식 프로젝트이며, 게임 APK를 포함한 공식 리소스는 제공하지 않습니다.

본 리포지토리에는 다음 항목이 포함되어 있지 않습니다.

* 게임 애플리케이션 및 공식 게임 리소스
* 실제 사용자 계정, 개인정보 및 인증 정보
* 공식 서버 접속 기능 또는 공식 인증을 우회하는 기능

---

## 주요 기능

### 프리 라이브

* 프리 라이브 진입 및 세션 처리를 지원합니다.
* 라이브 시작 및 종료 상태를 관리합니다.
* 플레이 결과와 하이 스코어를 저장합니다.
* 콤보, 클리어 여부 및 스코어 랭크를 반영합니다.

### 라이브 결산 및 보상

* 라이브 완료 후 점수와 보상을 정산합니다.
* 사용한 라이브 부스트 비율에 따라 보상 배율을 차등 적용합니다.
* 코인, 아이템, 랭크 경험치 및 이벤트 포인트를 지급합니다.
* 악곡별 최고 점수와 클리어 기록을 저장합니다.

### 라이브 부스트

* 서버 시간을 기준으로 30분마다 라이브 부스트를 충전합니다.
* 라이브 시작 시 설정한 비율에 따라 부스트를 소비합니다.
* 회복 아이템과 스타를 사용한 충전 기능을 지원합니다.
* 남은 부스트 수량과 다음 회복 기준 시간을 저장합니다.

### 에어리어 아이템

* 에어리어 아이템 구매 기능을 지원합니다.
* 아이템 레벨 업그레이드 기능을 지원합니다.
* 에어리어별 아이템 설치 및 교체가 가능합니다.
* 설치 상태를 영구적으로 저장합니다.

### 프로필 관리

* 유저 이름과 소개 메시지를 변경할 수 있습니다.
* 대표 캐릭터와 일러스트를 설정할 수 있습니다.
* 메인 칭호와 서브 칭호를 변경할 수 있습니다.
* 프레임과 핀즈를 변경할 수 있습니다.
* 프로필 공개 설정을 저장합니다.

### 밴드 및 덱 편성

* 메인 밴드를 변경할 수 있습니다.
* 밴드 멤버 구성을 변경할 수 있습니다.
* 일반 덱과 이벤트용 덱을 저장합니다.
* 덱 이름과 편성 프리셋 상태를 유지합니다.

### 하이스코어 레이팅

* 악곡과 난이도별 최고 점수를 저장합니다.
* 밴드별 하이스코어 레이팅을 계산합니다.
* 계산된 레이팅 결과를 프로필과 미션 데이터에 반영합니다.

### 데일리 로그인 보너스

* 한국 표준시를 기준으로 일일 접속 여부를 판정합니다.
* 로그인 보너스 진행 일수를 저장합니다.
* 동일 날짜의 중복 수령을 방지합니다.
* 일별 최초 접속 시 지정된 7개의 보상 중 진행 일수에 해당하는 보상을 지급합니다.

### 미션

* 지정된 조건에 따라 미션 진행 상태를 갱신합니다.
* 완료된 미션의 보상 수령을 지원합니다.
* 미션 진행도와 보상 수령 상태를 저장합니다.

### 로컬 상태 저장

변경 가능한 유저 데이터는 SQLite 데이터베이스에 저장됩니다.

기본 저장 위치는 다음과 같습니다.

```text
state/db.sqlite3
```

## 서버 구조

`main.py`를 실행하면 다음 세 개의 서버 구성 요소가 함께 실행됩니다.

| 서버             |  기본 포트 | 프로토콜      | 역할                                     |
| -------------- | -----: | --------- | -------------------------------------- |
| Kakao Server   | `8480` | HTTP      | 인증 및 SDK 요청을 처리합니다.                    |
| Session Server | `8481` | WebSocket | 로그인 세션과 게임 세션 통신을 처리합니다.               |
| Game Server    | `8482` | HTTP      | 게임 데이터, 라이브, 덱, 프로필 및 에어리어 API를 처리합니다. |

Kakao Server와 Game Server는 별도의 자식 프로세스로 실행되며, Session Server는 메인 프로세스에서 실행됩니다.

## 클라이언트 호환성

본 서버는 별도의 수정 절차를 거치지 않은 공식 게임 클라이언트와 직접 호환되지 않습니다.

클라이언트의 Kakao Server, Session Server 및 Game Server 주소가 로컬 서버 주소로 수정되어 있어야 합니다.

또한 Session Server는 현재 서버 구현에 맞추어 WebSocket 연결을 사용하도록 설정되어 있어야 합니다.

## 요구 사항

* Python 3
* Git
* Android 기기 또는 에뮬레이터
* Termux 또는 Python을 실행할 수 있는 PC 환경

필요한 Python 패키지는 다음과 같습니다.

```text
websockets
protobuf
pycryptodome
flask
```

---

## Termux에서 실행

서버와 게임 클라이언트를 동일한 Android 기기에서 실행하는 방식입니다.

```bash
pkg update -y
pkg install -y git python

git clone https://github.com/NatsuFlatWhite/krdori-v2.git
cd krdori-v2

python -m venv env
source env/bin/activate

python -m pip install --upgrade pip
python -m pip install websockets protobuf pycryptodome flask

python main.py
```

클라이언트의 서버 주소는 Android 기기의 로컬 주소를 가리키도록 설정해야 합니다.

```text
127.0.0.1:8480
127.0.0.1:8481
127.0.0.1:8482
```

---

## setup.sh 사용

다음 명령어를 사용하여 설치 및 실행 과정을 자동으로 진행할 수 있습니다.

```bash
curl -L https://raw.githubusercontent.com/NatsuFlatWhite/krdori-v2/main/setup.sh -o setup.sh
chmod +x setup.sh
./setup.sh
```

`setup.sh`는 필요한 패키지와 Python 가상 환경을 구성한 뒤 서버를 백그라운드에서 실행합니다.

서버를 종료하려면 다음 명령어를 사용합니다.

```bash
pkill -f "python main.py"
```

## PC에서 실행 및 ADB Reverse 연결

PC에서 서버를 실행하고 Android 클라이언트가 `127.0.0.1` 주소를 통해 접속하도록 하려면 각 포트를 ADB Reverse로 연결해야 합니다.

```bash
adb reverse tcp:8480 tcp:8480
adb reverse tcp:8481 tcp:8481
adb reverse tcp:8482 tcp:8482
```

연결 상태는 다음 명령어로 확인할 수 있습니다.

```bash
adb reverse --list
```

ADB Reverse 설정은 기기를 재부팅하거나 ADB 연결을 초기화할 경우 해제될 수 있습니다.

## 알려진 이슈

아래 항목은 특정 클라이언트 상태 또는 기존 저장 데이터에서 발생할 수 있으며, 최신 버전에서의 재현 여부를 확인하고 있습니다.

### 에어리어 아이템 중복 설치

에어리어 아이템이 설치된 상태에서 같은 종류의 아이템을 추가로 구매하면, 기존 아이템이 교체되지 않고 여러 아이템의 효과가 동시에 적용될 수 있습니다.

예를 들어 에도가와 악기점에서 `스튜디오 마이크`를 설치한 뒤 `록 마이크`를 구매하면, 외형은 `스튜디오 마이크`로 유지되지만 두 아이템의 에어리어 효과가 동시에 적용될 수 있습니다.

### 라이브 부스트 충전 계산

부스트 충전 직전의 잔여 회복 시간 또는 최대치 경계에서 클라이언트 표시값과 서버 저장값이 일시적으로 다르게 표시될 수 있습니다.

### 데일리 로그인 보너스 상태

기존 버전에서 생성된 데이터베이스를 사용할 경우 로그인 보너스 진행 상태가 비정상적으로 초기화될 수 있습니다.

### 에어리어 맵 진입 시 새로운 데이터 메시지 표시

에어리어 맵 진입 시 `새로운 데이터가 있습니다` 메시지가 표시되는 현상이 있습니다.

현재 `영춘 만세! 경사스런 새해!` 이벤트 데이터와의 연관성을 원인으로 추정하고 있습니다.

### 에어리어 진입 시 캐릭터 애니메이션 중첩

특정 에어리어에 진입할 때 과도하게 많은 캐릭터 애니메이션이 동시에 재생되는 현상이 있습니다.


버그를 제보하실 경우 다음 정보를 함께 첨부해 주시면 원인 분석에 도움이 됩니다.

* 재현 순서
* 서버 로그
* 관련 HTTP 또는 WebSocket 요청 경로
